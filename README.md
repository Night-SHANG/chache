## 变更与验证

- 保留已选Dustyroom DM-CGS-32原音色与完整187.143ms长度。原24位素材原样留存；游戏WAV仅转换为原幅16位PCM，不做EQ、变调、裁切、淡入淡出或重复声。
- 按钮声在播放时单独乘0.2428740327036814，使其有效峰值约0.24，相对v1.0.8提高约12.04dB。幅度4倍不代表主观响度4倍；不新增设置项。
- 浏览器/微信的音效总音量仍为0.45/1；原12种业务音效、BGM、图集不变。局内暂停BGM仍为0.12，继续为0.18；切到后台仍暂停，同一音乐播放器不重建、不从头播放。
