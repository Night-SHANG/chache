# 爆仓：最后一格 · v0.13.0

入库按订单配货，出库把同色货物连到出口；两个模式都需要给叉车留路。

本次入库五班和无限保留困难、专业两档，每日固定困难。困难累计得分1.5倍、专业2倍；金币只从最终分数兑换一次。五班和无限没有加急或清扫，每日前四班加急6%、末班新货全部加急，开局先选清扫。

主页新增复用现有图文的玩法说明，暂停说明保留。去掉强制教程、开关和练习；四个入库入口从开局可见，未开放的门灰显。危险箱、工具最多两种、出库四档与外观保留。

操作见[试玩说明](docs/v0130-playtest.md)，验收见[验证记录](docs/v0130-validation.md)。

## 打开试玩

完整解压ZIP。Windows已安装Node.js时双击start-preview.cmd，启动后打开http://127.0.0.1:4173/。关闭命令窗口停止服务。macOS/Linux在目录中运行node scripts/serve.mjs。已构建试玩无需安装项目依赖；Node.js官方来源为https://nodejs.org/，开发基线为Node24。

请通过启动器的HTTP地址打开。浏览器需要Web Locks以保证同一份记录只由一个窗口保存。第二个窗口会只读；返回原窗口继续。使用相同浏览器和地址保留本地记录。

微信开发者工具导入build/wechat为小游戏，目录含真实game.js/game.json，AppID留空供有权限的开发者填写。本项目没有申请凭据、上传或正式发布微信版本。

## 保存与版本

新入库五班、每日与无限均为规则18；五班／无限只提供困难与专业，每日固定困难。两档五班均可沿同一局／同档继续加班。普通出库12、无限出库13保持。已存在的旧局继续原来的规则；要体验新规则请正常结束旧局后新开，无需清缓存或删除钱包。

钱包、库存、永久外观权益、当前新局与领取记录共同提交到双副本。确认回主页结束当前棋盘，保留已得金币并退回未用道具；取消退出不改记录。后台和意外关闭恢复仍活跃的局。每日日期在开局时固定，跨午夜完成只结算原挑战日期，次日挑战仍可进入。

普通新局与重开分配新seed，每日同日期固定seed。没有在线排名或服务器校时。本地校验用于减少重复结算并发现损坏，不能防止手工改档、全库回滚、清缓存或跨设备丢失。没有远程账号、云同步、充值、广告或体力。

## 开发与验证

以下命令用于完整源码备份；轻量试玩包不含源码、测试或开发依赖。依赖由package-lock.json固定，恢复依赖使用npm ci --ignore-scripts。常用任务：npm run lint、npm run typecheck、npm test、npm run preflight、npm run build。

- src/domain：独立规则、确定性生成、四邻接/BFS、出货连锁与回放；旧规则指纹保持。
- src/application：统一账户事务、收益、道具预留、历史分段、帮助状态和旧档兼容。
- src/presentation与src/platform：Canvas2D、共享触控几何、生命周期和声音。
- scripts/host-static-help.mjs：未修改 game.js 在原生 Canvas/wx 模拟宿主中的真实输入、画面、生命周期与账户验证。
- artifacts/v0130-host：同一实际构建的菜单、帮助、两档、每日、入口、续局、恢复与账户证据。

普通构建默认关闭开发诊断；npm run build:debug仅供开发复现。build-manifest.json、CHECKPOINT.json和包内SHA256SUMS记录源与产物。完整开发备份保存源码、Git历史及验证证据。

离屏宿主不等于真实浏览器、Windows GUI或微信真机。真人手感、音频听感、设备兼容和实际平衡仍需相应环境验证。旧大样本不能直接套用到本轮规则；既有192局是规则16订单量研究，不是新每日困难与新倍率的真人通关率。
