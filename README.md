# 爆仓：最后一格 · v0.3.1 本地开发版

> 当前为本地开发版本，规则v3，数值尚未平衡。它不是微信审核包，也不是完整正式版。旧v1/v2存档继续按原规则执行，新开局进入v3。

## 怎么玩

拖动底部货物进入7×7仓库，也可点选货物后点棋盘。相同图标的货箱上下左右连成组，达到订单数量，且叉车能沿空地走到旁边，就会整组自动出库。清出的通路可能继续完成旧订单，形成连锁。

- 初次进入单候选教学：两次放置完成首次真实出库，再通过清墙演示堵路连锁。教学不计正式成绩。
- 不允许旋转；门口被货物占用会堵住叉车。
- 每6单进入下一班，共5班；每4单选择一个升级。
- 全部候选都放不下时爆仓；“四件候选”升级后会有4个候选。结果页可立即重开；标准五班胜利后可主动选择加班，保留棋盘继续追分，也可主动结束。
- Shift3开始可能出现特殊货件：托盘1格计2；加急显示剩余有效放置数，到期变废弃物；危险品出货清相邻废弃物；万能可参与当前订单货类。
- 升级能改变路线、货物生成、订单和清障。侧门等新效果均有说明，具体数值仍是可调开发配置。
- 主页提供标准新局、本地每日挑战、继续和设置。每日使用客户端北京时间日期和固定seed，无服务器校时或在线公平性保证。
- 长期Profile与单局独立保存；设置可开关声音/简化动效，选择纯外观；无永久战力。重置长期记录不会删除当前局。
- 每次完整规则结算后自动保存；下次打开可恢复。暂停或切后台不重复计算出货。
- 右下“状态”查看seed/规则版本/RNG/订单路线/生成权重与checksum。坏档会保留原文，不自动当作正常存档。

## Windows 本地预览

1. 将ZIP完整解压到一个目录，不要只拖出某个文件。
2. 如电脑已安装Node.js，双击 `start-preview.cmd`。它只在本机启动HTTP预览并打开浏览器。
3. 浏览器地址为 http://127.0.0.1:4173/ 。关闭命令窗口即停止预览。
4. 如没有Node.js，可先尝试双击 `build/browser/index.html` 查看；不同浏览器对本地文件存储/音频的支持可能不同，因此HTTP方式优先。
5. 需要安装Node.js时，请用户自行从 https://nodejs.org/ 下载官方版本。开发/测试基线为Node 24，单纯已构建HTTP预览不需要安装项目依赖。

此版本没有远程服务、登录、支付、广告或数据上传。存档只在当前浏览器/微信宿主内，换浏览器或清理应用缓存不会自动迁移。

## 微信开发者工具导入

1. 使用官方微信开发者工具，新建/导入“小游戏”项目。
2. 目录选择 `build/wechat`，其中有真实 `game.js` 和 `game.json`；不要导入浏览器目录。
3. 选择自己的小游戏AppID（`project.config.json`故意留空）；需要账号具备对应项目开发权限。
4. 本任务没有申请、读取或配置密钥，没有上传代码或发布版本。
5. 导入后先记录开发者工具版本、基础库版本与设备型号，再检查启动、触控、音频、切后台恢复、安全区、30fps/60fps表现。
6. 微信开发者工具与真机尚未验证，不能把本机宿主模拟视为通过。详见 `docs/validation.md`。

## 目录

- src/domain：纯TS规则、BFS、连通组、旧订单连锁、seed、replay
- src/application：统一会话、稳定保存点与坏档保护
- src/presentation：共享Canvas2D画面、布局、输入与瞬态表现
- src/platform：浏览器/微信薄层，输入、存储、生命周期、声音、图片
- scripts：构建、预览、Preflight、模拟与验证
- tests：规则/回放/输入/保存/平台/画面契约测试
- docs：设计依据、当前验证记录与后续门槛
- artifacts：验证日志、宿主模拟渲染图；不会进入微信游戏包
