# 货箱最后一格 v1.0.21 · 安卓音效音量校准

微信、浏览器与 Android 使用同一份单包资源代码。商店只保留场景、货箱、叉车三个单品分类，移除套装入口与优惠。保持v1.0.15以来已停售的外观目录不变。历史购买记录与库存保留；已装备的退役外观安全显示经典默认外观，金币与其他进度保持。音乐文件、音量与编码不变。

浏览器、微信保持直接绘制与输入，PNG未就绪时沿用现有同步画法。Android在原生启动画面背后准备当前首屏实际需要的场景和叉车PNG，再以当前屏幕几何完成绘制与原生视觉回调后揭示；不显示额外检查或加载文字。图片失败或达到故障上限后使用稳定降级画面，迟到图片不会替换已揭示的首屏。背景冷态与就绪态共用长屏布局。实际启动失败显示原因。装备仍直接走已有账户事务；图片完成或失败不写存档。以现有安卓按钮声为参考，提高其余12个较低游戏音效的素材音量；只做线性音量增益，原音色、时长、反馈触发和游戏逻辑不变。浏览器、微信、按钮声及背景音乐保持原样。

## 打开与继续旧存档

试玩包完整解压，关闭上一版游戏页和服务。Windows安装Node.js24后双击start-preview.cmd；macOS/Linux执行node scripts/serve.mjs，打开http://127.0.0.1:4173/。

必须沿用原浏览器、用户配置与原网址来源；127.0.0.1和localhost不是同一个存档来源。不要清站点数据或使用无痕窗口；关闭旧页再打开新版。沿用原存档键和账户格式。浏览或购买不会自动装备。

微信工程位于build/wechat，由有权限的开发者填写原AppID。全部内容都在主包，没有外观分包或下载接口。原始主包大小按最终构建报告计量；这是供用户导入开发者工具核验的单包，尚不能声称通过微信工具处理后的包体限制。没有上传、提审或公开发布。

## 构建与验证边界

使用Node.js24，运行npm ci --ignore-scripts，再执行npm run lint、npm run typecheck、npm test、npm run preflight。正式构建为npm run build:production；Android网页staging为npm run build:android。新Android标识为v1.0.21/vc11；staging构建不代表已生成或签名APK。

历史两项美术母图缺失检查保留，不能表述为全量测试全绿。运行PNG和当前构建不依赖这两张缺失母图的重新生成。当前三页真实截图使用生产renderer与native Canvas，不能替代浏览器、微信开发者工具或实体手机验证。
