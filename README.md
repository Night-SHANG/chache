# 货箱最后一格 v1.0.13 · 静态美术纹理化

这是在 v1.0.12 基础上，把现有复杂静态仓库、货箱、叉车、道具和商店预览改成离线生成的本地 PNG 纹理的版本。保留已确认外观、拖拽优化、触屏落点、音频与账户数据。微信采用主包加一个普通外观分包；供本地体验验收，不代表已经上传、公开发布或已经解决手机黑屏。道具价格为旋转80、清障120、万能160金币；三种道具支持确认框内减/加数量。43件收费外观按原价，14个固定套装按本次未拥有部件数计价：3件8折、2件9折、1件原价，合计向上取整；0件不收费。5项基础外观免费，蓝/红叉车仍按成就解锁，经典预设中的工程白600金币无套装折扣。

## 打开与继续旧存档

完整解压ZIP，先关闭上一版游戏页和启动服务。Windows已安装Node.js24或更新版本时双击 start-preview.cmd；macOS/Linux运行 node scripts/serve.mjs，然后打开 http://127.0.0.1:4173/。

必须继续使用原来的浏览器、浏览器用户配置和网址来源（协议、主机、端口全部一致）。127.0.0.1与localhost是两个不同来源；如果原来使用localhost，请保持原来的地址。不要清浏览器缓存/站点数据，也不要开无痕窗口。第二个游戏窗口只读；请关闭旧页后在新页继续。

沿用原存档键与账户格式，不新建隔离空档，不清空金币、库存、已拥有、已装备或成绩。之前免费领取的商品继续保留，不重复收费、不追回。浏览或购买不自动装备；套装只购买缺少部件。每局依然最多携带两种道具、每种一件。

微信工程在 build/wechat，需要有权限的开发者自行填写原AppID。账户存储键保持；是否共享存档仍取决于微信项目/账号/运行环境是否相同。未申请凭据、上传、提审或公开发布。

## 变更与验证

- BGM、日/夜班启动背景与基础外观在主包；额外主题、付费外观与商店预览在一个普通 cosmetics 分包。不增加 CDN 或外部资源域名。
- 先读已装备外观，再等待它所需图片。加载中显示提示，失败显示原因与重试；不因图片失败替换为默认外观，不写回装备或存档。BGM 保持原来的独立生命周期。
- 浏览器及 Android 网页 staging 一次附带全部本地资源；微信在需要时用官方 loadSubpackage。旧微信缺少此接口会明确提示更新，不直接调用缺失 API。
- 复杂静态美术不再在运行时创建离屏画布；棋盘轻量渐变、接缝、标记、文字及动态信息保留。日/夜背景透明外侧与有限背景边界保留。
- 图片来自原有画法的离线渲染，完整保留当前与历史可兼容外观源。有限像素图片在任意缩放下的抗锯齿可能与实时矢量略有不同。
- 玩法规则、付费商店、字号布局、音量、存档键和账户格式不变。依赖图未升级。正式构建为 1.0.13，关闭开发诊断。
- 构建启用代码压缩，并在微信工程配置启用上传自动压缩（setting.minified）。主包及分包原始字节数不等于微信工具处理后的上传大小；开发者工具与实体手机仍需验证。
- 详细验证与限制见 docs/v113-static-textures.md。历史两项美术母图缺失检查保留，不能表述为完整测试全绿。
- 本次仅构建 Android 网页 staging，不编译、签名或交付新 APK，不设置 Secrets，不触发 Android CI；已交付的 v1.0.10 APK 不变。
- 上一版 README 原文保留于 docs/v112-entry-readme-history.md。

## 开发与重建

完整源码包使用Node.js24或更新版本。执行 npm ci --ignore-scripts，然后分别执行 npm run lint、npm run typecheck、npm test、npm run preflight。正式构建为 npm run build:production；显式免费开发校验为 npm run build:playtest，不能将它作为本次用户正式包。

完整测试保留两项历史美术母图缺失检查，不删除或放宽以制造全绿。已验证运行PNG图集和本轮构建不依赖重新生成这两张历史母图。原始母图全量重建仍不可声称恢复。

实际浏览器GUI、Windows启动器GUI、微信开发者工具与实体手机未经本轮验证。原样JavaScript的DOM事件/原生Canvas宿主验证不能替代这些环境。用户体验与设备兼容仍由本地测试确认。
