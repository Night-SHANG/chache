# 爆仓：最后一格 · v0.12.0

入库按订单配货，出库把同色货物连到出口；两个模式都需要给叉车留路。

本次 v0.12.0 将加急与清扫集中到每日挑战：每日前四班6%，末班新货全部加急，每次开局先选清扫方式。入库五班与无限不再出现加急，也不再选择清扫。

五班提供普通、困难、专业三个订单量档位，供这次试玩比较，分别记录成绩。基础入库教学仅教放货、凑单与通路；每日有独立提示。设置新增教程开关和三种可反复体验的教学练习，练习不发金币、不记成绩、不改每日领奖。

操作与打开方式见[试玩说明](docs/v0120-playtest.md)，验收见[验证记录](docs/v0120-validation.md)，三档自动策略对照见[订单量研究](docs/v0120-order-study.md)。出库、商店外观、工具与金币兑换延续上一版。

## 打开试玩

完整解压ZIP。Windows已安装Node.js时双击start-preview.cmd，启动后打开http://127.0.0.1:4173/。关闭命令窗口停止服务。macOS/Linux在目录中运行node scripts/serve.mjs。已构建试玩无需安装项目依赖；Node.js官方来源为https://nodejs.org/，开发基线为Node24。

请通过启动器的HTTP地址打开。浏览器需要Web Locks以保证同一份记录只由一个窗口保存。第二个窗口会只读；返回原窗口继续。使用相同浏览器和地址保留本地记录。

微信开发者工具导入build/wechat为小游戏，目录含真实game.js/game.json，AppID留空供有权限的开发者填写。本项目没有申请凭据、上传或正式发布微信版本。

## 保存与版本

新入库普通、每日与无限均为规则16，普通出库12、无限出库13。五班的困难与专业通关后结算，普通档可继续加班；每日和直接无限仍用普通档订单量。已存在的旧局继续它原来的规则；要体验新规则请正常结束旧局后新开，无需清缓存或删除钱包。

钱包、库存、永久外观权益、当前新局、教学与领取记录共同提交到双副本。确认回主页结束当前棋盘，保留已得金币并退回未用道具；取消退出不改记录。后台和意外关闭恢复仍活跃的局。每日日期在开局时固定，跨午夜完成只结算原挑战日期，次日挑战仍可进入。

普通新局与重开分配新seed，每日同日期固定seed。没有在线排名或服务器校时。本地校验用于减少重复结算并发现损坏，不能防止手工改档、全库回滚、清缓存或跨设备丢失。没有远程账号、云同步、充值、广告或体力。

## 开发与验证

以下命令用于完整源码备份；轻量试玩包不含源码、测试或开发依赖。依赖由package-lock.json固定，恢复依赖使用npm ci --ignore-scripts。常用任务：npm run lint、npm run typecheck、npm test、npm run preflight、npm run build。

- src/domain：独立规则、确定性生成、四邻接/BFS、出货连锁与回放；旧规则指纹保持。
- src/application：统一账户事务、收益、道具预留、历史分段、教学和旧档兼容。
- src/presentation与src/platform：Canvas2D、共享触控几何、生命周期和声音。
- scripts/host-daily-guides.mjs：未修改 game.js 在原生 Canvas/wx 模拟宿主中的真实输入、画面、生命周期与账户验证。
- artifacts/v0120-tier-integration：192 条既有研究轨迹与实际规则16的命令、随机状态、结果及严格存档对齐。

普通构建默认关闭开发诊断；npm run build:debug仅供开发复现。build-manifest.json、CHECKPOINT.json和包内SHA256SUMS记录源与产物。完整开发备份保存源码、Git历史及验证证据。

离屏宿主不等于真实浏览器、Windows GUI或微信真机。真人手感、音频听感、设备兼容和实际平衡仍需相应环境验证。旧大样本不能直接套用到本轮规则；本轮192局也只是两种限定策略和固定种子的经验样本，不能当作真人通关率。
