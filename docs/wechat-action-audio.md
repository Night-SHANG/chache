# 微信正向操作音效小幅提升

本次按用户要求，只把微信的放置、路径就绪、叉车运输、订单完成、连续完成与换班/阶段完成提示提高约2dB。具体为place、route_ready、forklift、ship、chain2、chain3、chain4、shift共8项。pick、invalid、fail、legacy upgrade、ui_click及其专用gain保持；BGM文件、正常/暂停音量和生命周期保持。

## 实现边界

在构建时从既有音频字节生成微信专用PCM16输出，对8项逐采样乘10^(2/20)并舍入，范围外直接拒绝构建，不用削波器掩盖超幅。原place已有的2dB不撤销，因此本次相对于v113再加2dB、相对于原始合成器合计4dB。微信运行期volume仍为1，不传大于1的值。

同一文件路径替换输出，不增加音效文件数量；生成器、声调、时长、采样率、声道、播放事件和共用运行源码不变。browser默认路径不增益；Android继续从browser输出复制媒体，不引入微信增益。manifest如实分别记录place总增益与微信额外增益列表。

## 验证

先写逐样本回归，旧代码在place样本72以3≠4失败；增加平台参数后、尚未修改实际build输出时，产物回归亦在微信place字节不同处失败。最终14项PCM/平台/原混音测试通过，另6种生产与开发构建政策测试、1项正式构建检查通过。独立复核没有未解决阻断；复核发现的两处旧双平台manifest全等假设已改为精确校验差异并保留其余字段全等。

初次新工作树未链接Android shell依赖，出现10项环境失败及2项既有缺母图失败；链接既有锁定依赖后恢复。中间完整测试发现5项旧manifest断言失败，已保留日志并修正；不以删除检查或跳过求绿。完整最终结果与实际产物指标见qa/wechat-action-audio/summary.json。

本分支没有版本号升级、APK编译、签名、CI、微信上传或公开发布。物理手机听感与微信开发者工具处理后包体尚未验证；离线+2dB不承诺不同手机扬声器上的主观响度完全一致。最终测试包版本及与其他改动的整合另行绑定，不能混入未确认Android启动WIP。
