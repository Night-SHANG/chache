# v0.12.0 试玩说明

完整解压后，Windows双击start-preview.cmd。继续使用原浏览器和 http://127.0.0.1:4173/ ，即可沿用金币、外观和记录；无需清缓存。需要已安装Node.js，试玩包无需安装开发依赖。

## 本次更新

- 新开的入库普通五班和无限都取消加急货及清扫选择。普通通关后继续加班也一样。
- 每日挑战保留加急：前四阶段6%，最后阶段新来的货件全部加急。每次开局都先选“每2单”或“每6次放置”清理1格废弃物。
- 入库新手引导简化为实际放货、凑订单与留叉车通路。加急倒数的简短提示移到首次玩每日时，在加急真正放上棋盘后出现；每天货物顺序不会因为看过或跳过提示而改变。
- 引导进度分别保存；已有基础进度继续有效。跳过只关闭讲解，仍需完成每日开局的清扫选择。
- 出库四档及普通／无限、外观商店、道具、金币兑换和每日通关奖励保持。

恢复旧局仍按它原来的规则继续，包括旧局的加急与清扫。结束旧局再新开，即可体验新规则，不需要删除任何记录。

真实浏览器、Windows GUI和微信设备尚未完成完整验收；本包在本地自动化与Canvas宿主中验证。

## 这次可直接比较的五班难度

在入库五班卡片选择“普通”“困难”或“专业”，再开始。三档都没有加急；各自记录分数。每日和无限仍使用普通档订单量。困难和专业通关后结算，普通通关后保留继续加班。

## 不清记录也能重看教程

设置中的“新手教程”控制正式游戏的自动提示；打开不会重置已经学过的步骤。想重看时点“重新体验教程”，选择入库基础、出库基础或每日加急。

手动练习始终显示引导，不改变教程开关。练习不会获得金币、记录成绩或影响每日领奖；当天已完成每日也能练习。若正在玩正式局，进入练习前会先确认是否结束本局，取消即可回到原局。
