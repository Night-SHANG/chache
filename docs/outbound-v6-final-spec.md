# v6 出库9×9与多形状双色规格

2026-10-06。依据用户实测文字及4张标注截图。稳定基线cc78c06（v0.5.0），原规则1–5冻结。此次涉及尺寸/坐标/存档身份，采用版本隔离的架构变更；本文件未授权的待定项不实施。

## 已明确方向

- 订单玩法显示名「入库模式」，副标题解释按订单配货、留叉车通路；规则与7×7保持。
- 新颜色玩法显示名「出库模式」，副标题解释同色连出口、叉车有空路。
- 所有新出库局9×9；现有三个档位保留混色20/30/40%，改名简单/中等/困难。
- 扩展双色形状，不只2×2；仍逐格算颜色、分别出货，异色留原格。
- 旧纯色不再向新用户提供新局入口，已有旧档需继续可读。
- 暂停页需明确重开；主页面需要整理，不能用多个“订单”按钮让人误以为是不同主模式。

## 已确认的实现选择与独立待定项

1. 已确认：专业档混色50%，延续每档+10个百分点的最小变化。不是已定平衡；不改简单/中等/困难原概率。若比较50/60，只作有界经验测量，不自动调参。
2. 已确认：双色仅4/5格，每色至少2格且各自四邻接连通。2/3格仍纯色，避免产生大量孤立单格。直接复用8个现有形状：square、i4_h、i4_v、l4_e、l4_w、s4_h、z4_h、p5。两色2+2或2+3。T4与十字5的中心星形结构不支持两色各至少2且各自连通，暂不加入双色池。
3. 已确认退出语义：回主页先询问“结束本局并返回主页？”，明确当前棋盘不保留、历史成绩与设置不变；安全按钮“继续游戏”优先。确认后标记本局结束，防备份复活；后台/意外关闭仍恢复。原run字节和其他兼容槽不永久删除。
4. 无限订单直接入口已授权，最小闭环另提v7规格：从低阶段逐步增长，独立成绩，不改变旧五班。已批准并按docs/inbound-endless-v7-spec.md实施。
5. 已确认红色堵路预警，基于本次完整规则结算后的实际棋盘，避免放下即出货清路却误警。警告不禁止合法落子；区分入口被占和入口虽空但空路被切断。

## 新出库9×9规则边界

仅在新rulesetVersion=6使用boardSize=9；固定门：北食品(4,0)、东化工(8,4)、西机械(0,4)、南叉车(4,8)。81格/四邻接/BFS全部基于新尺寸；不得复用旧硬编码7的toIndex或BFS。仍至少4件、30批、10分/格、原有5级形状开放、选一补一；不加入3件批补、移动门或新升级。

运输延用逐箱沿本色货线出库、空车回南入口。货线只走事件归属货格，不穿异色残留。不改变规则时钟或保存点。9×9最长路线更多，要逐帧检查插值、转角朝向、到门消隐和裁切；简化及后台取消不改变最终state。

## 生成确定性建议

每件固定六次抽签，所有档位同范围同顺序：类型1..100、纯色shapeRaw0..2^31−1、纯色cargoRaw同范围、混色shapeIndex0..7、分区量0..5、有序颜色对0..5。

先根据独立阈值20/30/40/50选择纯/混分支；六次抽签始终消费。混色shape均匀8选1，shape内合法无标签分区分别1/2/3种，用分区量mod分区数做到精确均匀；每个分区选择6种有序不同颜色对。共66种实际货件，但不将66种等概率一锅抽，避免分区多的P5被过量供应。混色池从开局可出，不受普通形状解锁限制，且不依据板面可放性重抽或降为纯色。

纯色继续原普通shape池与权重，但拥挤比的分母改为81。候选重复抑制与颜色库存权重保持规则族。相同seed/相同生成序号六个原始输入对齐；棋盘/保留候选/阶段分化后不承诺完整供货相同。

## 身份与兼容

建议新state要求mode=color_exit、rulesetVersion=6、boardSize=9、difficultyId=easy/normal/hard/expert、runConfigId=run.outbound9_v6.<difficulty>；旧colorTier仅属于v5，v6不得混用。尺寸/难度/逐格货类入checksum与Replay。

旧v4/v5仍49格，旧key和内容不变，不自动扩81格、不搬门、不重新抽候选。新v6 run key与成绩命名空间与全部旧档分开；新局选择不会把旧档误读为新档。若退出语义后来批准改变，也需保留旧run可恢复的迁移材料并明确生效边界。

Profile继续与单局分离，最高分不跨尺寸/规则/难度混排；设置外观共用。全局serial/重置边界统一枚举所有保留槽，读取失败不能当空；取消确认无副作用。

## 尺寸适配

棋盘显示区保持既有840逻辑像素，7格每格120，9格每格93⅓。只建立最小boardGeometry(state)及state-aware命中/坐标转换，不造通用引擎。入库和旧档必须保持旧像素几何，避免原运输回归。

手机实际触控格变小，保留拖拽与点选→落点两种方式。门位置、格内图标、残留描边、货线路径、叉车、候选预览均按对应格距。三尺寸实际构建测试，检查边角命中、拖出取消、长路线与文字遮挡。
