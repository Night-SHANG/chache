# v1.0.10 音频调整

仅调整两个混音参数：BGM整体降低2dB，放置货箱place提高约2dB。按钮ui_click继续使用v1.0.9原幅DM-CGS-32与专用播放gain0.2428740327036814；其他音效不变，不新增设置项。

## 实现

BGM文件保持相同字节，正常与暂停音量都乘10^(-2/20)=0.7943282347242815：正常从0.18变为0.14297908225037068，暂停从0.12变为0.09531938816691378。两种状态的相对差值保持，播放器、进度、后台暂停、关闭音乐与待确认恢复等规则不变。初始化和状态切换使用同一组有效音量。

place在构建素材加载层对原PCM16样本逐个乘10^(2/20)=1.2589254117941673后舍入；保留原生成器、头信息、单声道、22050Hz、2536帧和115.011ms长度。峰值0.2769775390625，实测RMS提高2.000010401393368dB，无削波。成品SHA-256：568f7a73096f5b5c35e87644b8123dab5595364666308a925923900c643241dc。

浏览器与微信place播放器音量仍为0.45/1，不把超过1的值传给微信音量API。每次素材生成都从原始未增益结果开始，重复构建或播放不会累乘。其他11个原有业务音效保持原字节；ui_click及其gain也保持。

## 验证

回归先验证正常/暂停BGM和place增益在旧代码上失败，再验证逐采样单次增益、RMS、无截幅、其他素材不变及微信合法音量；原暂停/后台/重试行为与按钮声策略同时回归。新双端原样生产音频宿主为scripts/host-audio-balance-v110.mjs，新增真实place操作和业务声优先验证；数值混音验证为scripts/verify-audio-balance-v110.mjs。

完整测试在本轮UI和音频改动合并后统一运行；定向结果不冒称全项目全绿，历史母图缺失另列。离线数值和模拟宿主并不等于实际扬声器试听。原幅ui_click.wav单独以音量1播放会绕过专用gain，不能代表最终游戏音量。
