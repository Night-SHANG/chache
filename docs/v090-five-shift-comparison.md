# 普通入库五班：旧版与无升级新版配对结果

固定种子、策略和清扫分支的 256 对无道具测试中，旧 rules9 通关 146/256（57.0%），新 rules11 通关 110/256（43.0%），差 -14.06 个百分点。该差异仅是两种固定机器人的观察，不是玩家胜率，也不能单独证明真人难度或乐趣。

正式研究共 896 局，457 局自然通关、439 局真实堵死失败、0 局封顶。512 局无道具基线先执行，再单独执行 384 局道具研究；20 局资源试测未重复计入。没有调参或挑选获胜种子。

失败分布显示：首班失败从 76 局降至 56 局，第2–5班失败从 34 局增至 90 局。新版在这些策略下更少卡在首班，却更难完成五班；本研究不能把差异单独归因于早期订单、急件或移除升级中的某一个改动。

## 独立道具研究

384 对比较各自匹配 rules11 无道具基线。每个无道具基线用于三个组合，不能把它们当作 384 个不同基线种子。按组合汇总如下：

合计通关次数由 198 增至 201（+3），新增救回 3 对，旧胜新败 0 对；完成订单均值差 +0.09。只在无合法落点后的救援阶段使用第一个合法道具方案，没有提前规划用法，因此不能代表道具全部策略价值。384 对在各自无道具终止前的命令前缀全部一致。

每个道具局假设免费带入两件不同道具；没有真实购买、扣费或钱包结算。实际单价为旋转80、清障120、万能160。基础金币使用真实公式：订单数 + min(floor(分数/1000), floor(订单数/2)) + 15×floor(订单数/30)。组合标价不混入基础金币，也不据此宣称回本。
