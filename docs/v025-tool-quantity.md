# v0.25 道具数量确认框

2026-10-10 18:37 北京时间（UTC+08:00），实现检查点，尚未最终验收。

范围仅为三种消耗道具的批量购买/免费领取。保留原商店列表、价格 80/120/160、每局最多携带两种且每种一件、50 项外观和 15 组套装展示。本轮交付仍为免费试玩；正式金币版待人工体验确认后另行推进。

## 局部研究与采用

- [No Man’s Sky Synthesis](https://www.nomanssky.com/synthesis-update/)：数量调整与批量操作降低重复动作。
- [Stardew Valley 1.6 更新](https://www.stardewvalley.net/stardew-valley-1-6-update-full-changelog/)：批量操作与防双击处理说明便利操作需要误触保护。
- [Android 触控目标](https://support.google.com/accessibility/android/answer/7101858?hl=en)：48 dp 目标与间距参考。当前 1080 逻辑坐标中的减/加均 168×162，320 宽时约 49.8×48 px。

只参考交互语义，不复制第三方实现；沿用现有 Canvas 控件和 A/B 原子账户，无新增依赖或许可证义务。不将上述 PC/多平台游戏参考称作已核实的微信小游戏范例。

## 文字推演与边界

打开道具确认框 → 默认 1 件 → 减/加选择数量 → 实时显示合计和余额变化 → 左取消 / 右确认 → 整批提交。取消、调整数量、浏览均不写账户；重新打开恢复 1 件。

付费上限为现有安全整数库存余量与可负担数量的较小值；免费模式不除以零，只受既有库存容量约束。不新增 99 件之类业务上限。不足一件时显示 1 件并禁用确认；非法数量、溢出、报价或代际变化、余额不足均拒绝，不静默部分购买。

确认先消费临时弹窗，然后沿用 operationId、requestDigest、A/B 根与重试回执。相同提交重复不会多扣费或多发货，数量属于请求摘要；旧不带数量的单件请求和已保存回执仍可识别。确认/取消后的同位置短间隔点击被隔离，避免落到下方商品。存档格式不变。
