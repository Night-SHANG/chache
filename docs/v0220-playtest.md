# v0.22.0 商店与菜单导航

完整解压后运行 start-preview.cmd。商店道具和原有 53 项外观仍可免费领取。

- 外观分为套装、场景、货箱、叉车四个分类；双列列表可以上下拖动或使用鼠标滚轮。
- 点击卡片查看大图。返回列表保留原来的浏览位置；从套装查看单件后，返回原套装。
- 置顶经典套装可切换日班／夜班、经典货箱／醒目轮廓、黄／蓝／红／工程白叉车。选择只改变预览，点击“装备整套”才应用。
- 经典套装缺少选中的叉车时可先领取，再明确装备。正式版保留蓝、红叉车的成就解锁和工程白 600 金币单价。
- 其余十五套仍只对未拥有部件合计打八折并向上取整；试玩免费领取，已有权益不重复收费。
- 从主页重新进入入库默认为困难、出库默认为普通玩法、商店默认为道具。局内暂停、重试和继续仍沿用本局配置。
- 入库与出库的选择卡片统一宽度，开始按钮保持一致右侧留白。

本轮不增加美术资源，玩法数值、金币获取、音频与动画时长保持原样。套装预览是搭配展示，不是额外玩法。自动化 Canvas/wx 宿主验证与微信真机体验分别记录。
