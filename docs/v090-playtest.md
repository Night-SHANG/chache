# v0.9.0 试玩说明

完整解压后，Windows双击start-preview.cmd；继续使用原来的浏览器和 http://127.0.0.1:4173/ 地址即可保留记录。需要已安装Node.js；试玩包无需安装项目依赖。

本次新开入库恢复原来的订单需求，取消普通升级三选一，固定7×7仓库和3件待放货。清扫、加急、金币商店和三种道具保留。

- 商店中查看图标、作用、库存与价格；工具仍须开局前携带，每局最多2种。
- 点击页眉工具箱展开道具，选择后回到货物区操作。工具用过才消耗，取消不扣；未使用的工具在结束本局后退回库存。局内不购买工具。
- 开始新入库后，在棋盘上选择本局清扫方式。暂停、后台或意外关闭后仍恢复真实待选状态。
- 出库四种难度的普通/无限玩法保留，每组出货动画仍约1秒。

如果进入后恢复的是旧局，它仍沿用旧规则。确认结束旧局，再开新入库即可体验新版，无需清缓存。旧成绩、金币和库存保留，不把旧局悄悄转换为新规则。

已有历史记录的玩家会按需看到新机制短提示，不重新发放辅助开局。两种模式各自的新手引导仍可跳过；新版入库引导不再要求选择升级。

本包含浏览器预览及真实微信小游戏构建目录build/wechat；微信设备验收和正式上传尚未完成。自动测试与固定机器人测算不能代替真人手感和平衡判断。
