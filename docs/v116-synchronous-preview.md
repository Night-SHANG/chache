# v1.0.16 同步外观预览正式候选

本次恢复v110–v112已有的商店同步背景画法，保留当前准确的货箱/叉车/棋盘共享纹理。不是删掉文案后留空图，也不是新的页面延迟切换状态机。游戏大背景仍使用PNG，未恢复旧warehouse-cache/copy或全游戏背景程序重绘。

## 行为
- 一次启动固定准备8张共享图集及当前scene。进入商店后分类、页码、商品选中、图名价和操作即时同步，不请求逐项previewPNG。
- 装备动作先准备目标scene，成功后调用原账户事务。页面保留正确商品，按钮防重复；退出、后台、其他操作、账户代次或写锁变化取消过期动作。真实失败显示重试。保存不确定继续原账户恢复并保留所需scene。
- scene最多当前加一个目标驻留/在途，不解码全部大场景。

## 目录与资源
本次退休ice_vault/ice_crystal/ice、forest_depot/wood/timber、lava_forge/lava_core/lava。现29件在售，历史53权利仍能读取；退役装备显示经典，金币/工具/成绩/所有权不丢。无套装页面或优惠，微信仍全部主包。

17个运行PNG：9scene、8共享图集。9张已无运行用途的单品PNG（115,525字节）退出manifest与运行包；原始素材及历史仍保留。所有媒体原字节不变，音乐音量编码不变。

固定图集编码991,276字节，RGBA16,331,312字节（15.575MiB）；当前scene另9,254,400字节（8.826MiB）。这是像素引用预算，不含显示Canvas/GPU/宿主开销，不是真机总内存。默认启动9图较v115多3图、编码667,626字节；实际设备启动耗时未测。

## 验证边界
测试采用先失败再修复；重点覆盖即时完整预览、正确商品身份、装备前账户不可变、重复/取消/写锁/不确定保存恢复。三端以实际生产bundle+真实PNG+Canvas逐帧验证；不把模拟DOM/wx/bridge等同真实浏览器GUI/微信IDE/Android手机。最终全量测试与精确包体见交付报告。

保留两项历史母图缺失测试，不能声称全量全绿。微信IDE处理大小与实体设备仍需验证。本次先交微信/browser候选，Android网页staging同源码；v1.0.16/vc6标识不代表已签名新APK。
