# v0.7.3 整组装载验收

2026-10-06。用户明确改为参考入库的整组装载，取消逐箱取货。此选择取代v0.7.1/0.7.2的逐箱巡回，不再保留其复杂路径求解作为当前逻辑。

## 实现

叉车保留原入场空路，到货旁面向货组停100ms，复用入库collectPose的140ms整组抬起/收拢曲线，全部货物一次成为托盘载荷。随后沿本次Shipment.cells清空后的棋盘，取最短格数路线，同长优先少转弯，包括出门朝向。旧四候选巡回已从运行代码移除。

车按150ms/格、90°转180ms平缓移动，色口停180ms，离场240ms、外侧淡出180ms。装载件数只有0→整组N一次转换，之后带货到色口。整组收拢为用户选择的视觉抽象；车辆真实路径才受空格约束。残留异色不动，不能借未来连锁会清掉的格。
