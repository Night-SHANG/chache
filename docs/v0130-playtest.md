# v0.13.0 试玩说明

完整解压后，Windows双击 start-preview.cmd，再打开 http://127.0.0.1:4173/。继续用原浏览器和同一地址，不用清缓存。

## 本次调整

- 入库顶部只保留“困难／专业”。五班和无限跟随所选难度；每日挑战固定困难。
- 两档五班通关后，都可以沿同一局、同一难度继续无限。
- 困难得分为原始分的1.5倍，专业为2倍。金币按最终分数每120分换1币；每日通关的金币总额为基础金币的3倍，不再重复乘难度。
- 主页两种模式下面有“玩法说明”。选择入库或出库可看已有图文，入库详情也能看到每日特殊货物说明。暂停中的说明保留，返回后仍是当前对局。
- 去掉新手教程、开关和重播练习。新局直接正常开始，已有引导局也可自由摆放。
- 入库从开局就能看到四个入口：正在使用的门显示货类色，未开放的门灰显；四个入口格一直不能放货。

五班和无限没有加急与清扫。每日开局先选清扫，前四班加急概率6%，末班新来的货物全部加急。危险箱继续保留；五班／无限没有废物时，它按原货类正常出货。每日中，包含危险箱的货组出货时可清除该货组旁1格废弃物。

加急说明按原句显示：加急数字按后续成功放置次数倒数，不是倒计时

道具仍最多带两种、每种一件；每日不带个人道具。出库四档、外观、商店价格和每组约1秒动画保持。

## 保存

新入库采用规则18，旧局和旧成绩保留原身份。要体验这次难度与倍率，请正常结束旧局后新开。无需删除钱包、库存或外观。

确认返回主页会结束当前棋盘、结算已赚金币并退回未用道具；取消则继续当前局。后台或意外关闭仍恢复活跃的局。每日仍按开局日期记账，同一天已通关后不能再领，跨午夜完成不影响新一天的机会。

## 验证边界

本包以本地自动化及未修改的实际 game.js 在原生Canvas/wx模拟宿主中验证。真实浏览器、Windows图形界面、微信设备和真人难度体验仍需相应环境；自动测试通过不代表真人平衡已经确定。
