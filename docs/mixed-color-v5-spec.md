# 颜色出口 v5｜三档双色比较规格

2026-10-06。用户批准在同一包直接选择入门80/20、中段70/30、后段60/40，实际试玩后选取。名称仅为对比档，未承诺最终难度。原订单v1–v3、纯色出口v4保留兼容。

## 唯一实验变量

三个档每局固定混色概率：entry=20%、middle=30%、late=40%。每个新货件独立判定，初始三候选也包含；不是固定配额，不承诺短局恰好达到比例，不按棋盘可放性救场/重抽/降级。仍只补用掉的候选槽，其余保留；不改成三件批次。

三档其余条件相同：7×7、三个固定同色单门、南入口空路、每色4邻接且连到相应门、每组至少4件、每件10分、目标30批、每6批推进原纯色Shape开放档，无升级/特殊货件/每日/加班。一次放置完整连锁后判断≥30，最后可31/32。

## 货件生成

纯色：保持v4普通Shape目录、按档开放、基本权重/拥挤小件偏置/同候选重复抑制，以及三货类存量权重。

双色：仅现有2×2方块，恰好两色各2格，按整行或整列分带；不三色、不逐格随机棋盘纹、不旋转。三种货类的有序不相同颜色对6种×横纵2种，共12个固定合法图样等概率。此独立混色池从第1档可生成，不因纯色Shape.minShift或落点不合适改纯色。2×2放不下照常留作候选，并参与原无合法落点失败判定。

每次生成统一消费四个固定范围抽签：类型1..100、纯色Shape的31位随机量、纯色货类的31位随机量、混色图样0..11；总是计算两种候选描述，再按类型量≤20/30/40选择。加权映射用整数floor(raw×total/2^31)，其离散舍入明示为v5权重实现；类型比例本身用1..100精确区间，没有混色失败回退。所有范围与顺序固定，三档相同seed/相同生成序号的类型量和原始随机量相同；棋盘、候选保留、档位分化后，加权映射的货物结果仍可不同。

## 数据与结算

新增rulesetVersion=5、mode=color_exit、colorTier=entry/middle/late、runConfigId=run.color_exit_mix_v5.<tier>。tier和候选每格货类纳入checksum/Replay。未指定tier的v5创建/回放必须拒绝，不能悄悄使用中档。

Piece保留cargo作为首格货类，新增cellCargos?:CargoId[]，顺序对应SHAPES.cells；纯色不存该字段。混色必须shape.square、长度4、仅允许上述12图样，首格与cargo一致。不允许trait/rush。旧v1–v4拒绝此新字段，合法旧字节不变。

放置后每格按自己的货类进入board。连通组、出口、叉车空路、顺序、货线树均在平面货格上判定。一个双色件的一色出货时只清该色实际组，另一色留原格；不能按pieceId整件删除。可与旧库存合组，也可先清一色开路后清另一色。没有达到任一出口条件时不能因为是双色自动清空。

Shipment继续conveyor事件，cells和cargoPaths只属于正在出货的本色组。Session的中间快照必须按cellCargos还原新放置货件，不能一律用piece.cargo涂整块。动画表现延用逐箱货线/空车返南入口，暂停/后台/简化不改变规则。

## 存档和成绩

保留旧orders和color_exit(v4)槽；为三个v5档分别增加main/backup/temp/归档命名空间。当前模式选择器允许所有槽。新旧档不能串入其他难度，不能把v4读成v5。

Profile新增按tier分开的可选比较记录，旧colorExit仅保留v4；三档各有stats/best/lastRecorded/resetCursor。不污染订单成就、日榜或其他档成绩。全局runSerial分配必须检查所有有效槽，读取失败不能当空；重置时覆盖全部已知槽边界，终局无身份先拒绝重置。所有切换/新局确认取消、损坏主档+备份、存储失败、重载幂等延续v0.4保护。

## 选择与说明

颜色模式入口打开三档选择页，明确纯/混比例和“逐件概率”。每档可继续自己的局，或明确新开。旧纯色v4有兼容继续入口，不悄悄转换。选择页提供共同对比种子，切换不改既有局的seed；新开档使用显示的同一seed。换对比种子只影响以后新开，不覆盖现有进度。

候选、拖拽、落点影像按每格图标和颜色绘制，标“双色·食品/化工”等；未出货的异色必须可读。预览明确本次哪色/多少件会出货、双色中多少件留下；只有剩余异色也满足自己的出口与通路时才继续结算。第一张说明页示例不把两色合计4件误当任一颜色已达4件。
