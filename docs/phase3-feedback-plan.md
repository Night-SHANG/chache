# v0.3.1 表现收口与验收线

2026-10-06 北京时间（UTC+08:00）

## 已确认目标

保持06现有工业仓储/玩具货箱方向，增强可辨识、低干扰的放置与出货反馈；不改玩法、RNG、规则版本、计分或存档checksum。时间与强度是可调表现配置，不冒充已完成真人调校。

- 普通放置100ms轻微压缩与合法亮边，处于06的80–120ms范围。
- 每次出货：140ms路线点亮、350ms叉车canonical path移动、160ms货物轻抬/收拢到实际Dock，总650ms；先完成并保存Domain，再播放。
- 尘粒、Dock flash、Chain数字和Chain≥4脉冲均有上限，禁持续震屏；额外清障不冒充得分货物。
- 简化动效关闭位移、尘粒、脉冲，只保留必要路径/边框/文字，单次出货最多80ms，不加长操作阻塞。
- 12个预制原创短音：Pick、Place、Invalid、Route Ready、Forklift Move、Shipment、Chain2/3/4+、Upgrade、Shift Complete、Fail。Chain共享音色逐级升调；不依赖宿主运行时pitch兼容。
- 声音开关立即停止当前音效；后台/锁屏/主页/设置清除瞬态，不重新播放已保存出货。暂停与无效拖放不推进规则计时。
- 爆仓仅短暂轻压/中性提示，快速结算；按钮在失败过渡结束后出现，避免穿透。

## 分工与代码边界

音频仅扩平台适配与离线资源构建；Motion纯函数与Renderer只读ViewState；GameSession消费DomainEvent形成可取消瞬态/声音门。Input只发pick/ready/invalid反馈，不拥有规则。没有新渲染引擎、后台或依赖。

## 本地可验

1. TDD测试时间分段、简化动效、帧跳跃、音效恰好一次、预览重复不连播、合法/非法输入、取消与后台恢复。
2. 比较checksum，证明不同表现时钟/设置不改玩法；保存始终在动画前稳定点。
3. WAV完整性、长度、采样率、时长、起止平滑、音量峰值与确定性；两目标资源一致。
4. 实际game.js宿主在多个时间点渲染放置/点亮/移动/收拢/连锁/失败图；结合事件音序记录，不能称真实听觉测试。
5. 独立审查、全项目lint/typecheck/tests/Preflight/build与SHA校验，然后同Library身份新检查点。

## 仍须真人/设备

音量舒适度、升调识别、触控手感、爽感/低干扰审美，以及真实浏览器/微信音频中断与设备性能。测试字节、数值和模拟调用不足以宣称这些体验通过。10万–100万局与平衡验收仍保持未完成。
