# v0.11.0 试玩说明

完整解压后，Windows双击start-preview.cmd；继续使用原浏览器和 http://127.0.0.1:4173/ 地址即可保留记录，无需清缓存。需要已安装Node.js，试玩包无需安装开发依赖。

这次是界面整理：

- 出库先选择“普通”或“无限”，再从四种难度中开始。每张难度卡只有一个开始按钮，并显示当前所选模式的成绩。
- “使用道具最高分”单独记录实际使用过道具的对局；无记录显示“暂无”，真实0分仍显示0。
- 难度页不再展示倍率说明；既有难度加分继续生效。
- 两种无限玩法显示“无限 · 阶段N”，取消五阶段通关式进度条；完成单数或批数仍持续累计。普通玩法的进度保留。

当前规则、金币、加急概率、道具、存档和出货节奏沿用v0.10.0。切换普通/无限只是选择下一局玩法，不会转换正在恢复的局。准备页返回后保留刚才的模式选择。

本包仍为本地试玩版。真实浏览器、Windows GUI和微信设备验收尚未全部完成。
