# v0.11.0 试玩说明

完整解压后，Windows双击start-preview.cmd；继续使用原浏览器和 http://127.0.0.1:4173/ 地址即可保留记录，无需清缓存。需要已安装Node.js，试玩包无需安装开发依赖。

## 本次更新

- 出库先选择“普通”或“无限”，再从四种难度开始。每张卡只有一个开始按钮，显示当前模式的成绩。倍率说明已隐藏，原有难度加分继续生效。
- “使用道具最高分”记录实际使用过道具的局；无记录显示“暂无”，真实0分保留。两种无限HUD不再显示/5或通关式进度条。
- 新开普通五班与每日挑战到第五阶段后，新来的货件全部是加急，形状仍有大有小。已有货物和待放货不转换；普通前四阶段6%，每日前四阶段12%。直接无限一直6%；普通通关后继续加班，新货恢复6%，旧加急保留。
- 商店分“道具”和“外观”。主题、货箱、叉车分别预览和搭配；花金币永久解锁后，可免费装备与切换。新增木条货箱300、工程白叉车600、海港仓库900金币。
- 原有免费与成就外观权益保留；醒目轮廓免费，可叠加到木箱。清除游戏记录不会删除已拥有外观。只是外观变化，不增加属性或金币收益。

金币兑换、每日首胜三倍与当天完成锁、道具价格和出货节奏保持。新开的普通/每日采用规则15；恢复旧局仍按它原来的规则继续。结束旧局再新开即可体验第五阶段全加急，不需要删除原记录。

商店预览不扣币；购买需确认，购买后再选择装备。旧版已能验证的成就解锁及当前装备会保留；曾被清除且已无依据的历史解锁不能凭空恢复。

真实浏览器、Windows GUI和微信设备验收尚未全部完成。数值、价格和外观仍可在试玩反馈后调整。
