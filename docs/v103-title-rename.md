## 构建与旧档

使用Node.js24或更新版本。源码安装锁定依赖后运行 lint、typecheck、test、preflight，再执行 npm run build:production。

关闭旧游戏页和旧服务，完整解压新游戏包。继续使用原浏览器用户配置与同一来源（协议、主机、端口），不要清站点数据。Windows双击 start-preview.cmd；macOS/Linux运行 node scripts/serve.mjs。默认地址仍为 http://127.0.0.1:4173/；若旧档使用localhost，继续保持localhost。
