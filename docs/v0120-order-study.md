# 五班订单量三档测算

2026-10-07（北京时间）。本次包保留三档给实际体验，尚未决定哪一档成为日常主难度。

固定规则16普通五班、无加急／无清扫／无道具，种子1–32配两种只看当前信息的策略。每档64局，共192局，均自然结束、没有截断。不是64位真人或64个独立种子。

## 放下就能出货的区别

“这次放置发生出货”不等于“新货件自己就够订单”。按实际运走的新货格能否独自凑够数量统计，普通562/4041次放置（13.9%）、困难132/4010（3.3%）、专业65/3990（1.6%）。这只证明数量足够，不能假设把旧货移走后依然连通、路径仍可达。

更严格地看，整张已完成订单只运走本次新货的比例：普通411/1782单（23.1%）、困难81/1431（5.7%）、专业39/1311（3.0%）。不少“立即出货”仍借助已有货物或是旧库存恰好满足新订单。

三格货件在困难、专业中独自凑数量为0，源于两者最低需求4；但借助旧货依然可能放下就出货。实测三格货整体立即运走分别约52.5%、40.2%、37.8%（普通／困难／专业）。不能把它们都称为无需规划的出货。

## 解释边界

两种策略对较高需求反应不同：route的普通／困难／专业为25／19／16胜，greedy为24／10／4胜，各32局。因此这是这批固定策略的压力对照，不是真人通关率，也不是最高水平的成绩。

只统计赢下的局，平均成功放置约64.5／74.2／77.2次；它受“哪些局成功存活”影响，不能代表所有人玩一局的时长。困难和专业更依赖旧库存，盘面占用更高，但是否有趣仍需实际体验。

旧的“无加急无清扫43/64”实验将加急抽签区间映为普通货；当前规则16使用普通91%、托盘5%、危险3%、万能1%的连续区间。概率相同，具体种子的抽签映射不同，所以重新跑当前A得到49/64，不能直接复用43或说它是同一对照。

研究独立复放12,041条指令，核对4,524次出货分类和4,761项摘要值。专业8件单在当时的冻结研究副本里需要单独结构验证投影，真实记录的8件需求没有改成7；正式实现必须另外验证真实8件单保存与结算。研究审查通过不等于整个游戏的最终验收通过。

每日与无限在本包仍采用普通A需求；入库不新增难度得分或金币倍率。详细原始记录及审查见完整开发备份 artifacts/v0120-order-quantity-study。
