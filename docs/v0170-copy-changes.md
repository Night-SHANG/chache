## 与审阅建议的明确差异

- 试玩采用上表的真实短文案“领取→确认领取”“试玩免费”，没有照搬草稿中的“免费领取→领取”。商店标题仍为“金币商店”，没有采纳草稿的“试玩商店”；正常构建仍付费，试玩构建使用免费策略。
- 历史段／历史保存未确认、长期记录尚未读回、存储空间不足等提示保持原文：它们可能出现在没有重试或结束本局操作的页面，不能统一追加指令。
- 冻结玩法错误、旧教学和升级专属内容保持原文；没有把真实“出货”操作改为“入库”。
