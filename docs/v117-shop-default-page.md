# v1.0.17 商店初始页修正

## 范围
新进入外观分类或从主页重新进入商店、尚未主动选中商品时，默认浏览该分类第一件商品和第一页。装备状态只影响“使用中”标记，不决定初始浏览页；不写入账户。

保留同一次商店浏览中各分类已选择的商品和页码；切换分类、暂看道具后返回保留选择。购买确认取消、装备完成保留当前浏览页。重新从主页进入仍回道具页，并清除临时浏览选择。

## 原因与最小修改
session.resetShopVisit 已正确清空 cosmeticPreview，但 selectedShopCosmetic 将空预览回退到账户装备；cosmeticShopPage 由选中商品索引计算页码。已装备第二或第三页商品因此成为初始页。本轮仅将无有效预览的默认选择改为该分类首项，保留显式商品选择、详情、账户事务和资源生命周期。

## 验证
新增带有非首页装备的真实 session 冷进入、重新进入、三分类及账号只读回归，保留同次访问页记忆和购买/装备流程测试；同时增加三端实际 bundle 的初始页逐帧场景。最终测试和包体数字记录于交付报告。

v1.0.16 冻结包与历史保留；本轮不调整商品目录、美术、音频或资源分包。
