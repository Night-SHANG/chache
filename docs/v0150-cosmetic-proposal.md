# v0.15.0 物流外观扩展提案

状态：供评审的设计草图；不是已进入游戏的效果。基于 v0.14.0 / `8643d84` 的只读检查。本文及 `artifacts/v0150-design/` 不修改产品目录、账户、游戏 UI 或玩法。

## 目标与推荐

增加冷链仓库、铁路货站、快递分拣中心三个物流系列，每个系列包含主题、货箱、叉车各一件，共九件。系列仅用于美术组织：九件分别购买、分别装备，可以任意混搭；不加入套装奖励、套装购买或一键连带装备。沿用已有 Canvas 程序绘制风格，先评审结构草图，再制作和接入九件完整资产。

## 现状与必须保留的权益

- 目录现有 10 件：5 件无条件免费（日班、夜班、经典货箱、醒目轮廓、黄色叉车），2 件免费成就权益（首次正式出货的蓝色叉车、标准五班胜利的红色叉车），3 件付费（复古木条 300、工程白 600、海港仓库 900 金币）。因此“保留原有七项免费/成就权益”不等于首次登录即赠送全部七项。
- 醒目轮廓是独立布尔开关，不能占掉货箱样式；新旧所有货箱与废弃物均可叠加。旧版 `cargo.outline` 投影继续保留。
- 预览不写存储；确认购买只扣一次金币并增加永久拥有，购买后仍需单独免费装备。重复请求、双副本保存失败/重试、成绩重置和旧账户迁移的既有保护必须保留。
- 不改既有免费项、成就条件或三个付费价；不改金币收入、道具价或付费门槛。

## 资产边界与可读性

1. 货箱：保持五种货类原有色面与原图标。新增结构主要落在外框、顶部薄层、侧板，不以新材质色替代货类色。共用原来的 `icon`、特殊货物徽标与轮廓绘制；正常/大号紧急倒计时、危险/万能符号、托盘底座和废弃物不重画一套替代标记。草图展示五色与大号 3、危险标记，但不代替完整状态验收。
2. 叉车：本地 +x 为车头，保持中心/旋转点、同一前叉（约 x=31..61、y=±17）、装载锚点与当前运输路径。新车身可以在原包围范围内改变轮廓；不要求新车型每个像素的 alpha 与黄色车完全相同，但旧黄色/蓝色/红色/工程白基线仍应不变。不同“重载/短轴”都不增加载重、移动速度或可通行空间。
3. 背景：新主题与海港一样仅绘制有界背景，不改棋盘地板、格线、入口颜色、拖拽反馈或警告。三者靠建筑结构区分，装饰压低对比；无随机装饰、按帧新建离屏图或无界循环。
4. 预览与实际游戏最终调用同一套正式资产函数。草图仅在隔离脚本内，不能直接用草图冒充已完成的游戏预览。
5. 所有预览与装备都不碰棋盘、种子、RNG 状态、订单、紧急回合数、分数、奖励、工具库存或成绩桶。保温不延长紧急货物期限，重载不多搬箱，短轴不改变寻路；“试用”仅指商店查看外观，不新增试玩收益。

预览的现有构图使用 720×250 设计空间；缩放原本已受 816 宽度限制。288 高仍能容纳 283.33 高的主体，因此这里减少垂直留白，不缩小货箱/叉车。按钮短边至少 132，在 360 宽等比缩放后仍至少 44 CSS px。

选择语义：保留目录原顺序并在各类末尾追加新项；页面从该类别当前选中项的索引推导。翻页仅把临时预览选中项改为目标页第一件；上一页/下一页在边界禁用，不循环。不隐藏当前选中商品却让购买按钮指向它。切换分类或道具页签再返回时，恢复该类别临时选择及所在页；重新启动仍回到实际装备项，不持久化页码。确认弹窗锁定打开时的商品 ID，关闭/取消不改变拥有与金币。

货箱第一页仍含免费轮廓；它不成为第四类或额外收费项。预览其他类别时，使用“当前所选类别的临时选择 + 其余类别实际装备”，沿用现有规则；跨类混搭通过分别装备实现，不因翻页悄悄装备其它类别。
