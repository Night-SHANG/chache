# v0.7.0 试玩说明

这次简化了玩家界面，并让确定无法恢复的出库对局及时结束。

## 玩什么

- 入库：按订单配货并留出叉车通路。有普通五班、无限和每日挑战。
- 出库：同类货物上下左右连到同色出口，至少4件，叉车也要有空路能到货物旁。完成30批过关。双色货物按各格颜色分别出货，余下颜色留在棋盘上。

暂停中的“玩法说明”可以随时查看；初次互动教学可以跳过。四档仍是简单、中等、困难、专业。

## 这次调整

界面去掉了种子、比例、旧存档目录和开发说明。日常提示只保留目标、还差多少、未连出口、堵路与必要的保存警告。每日挑战仍保留；它每天提供固定一局。

新出库对局在一次落子完整结算后，如果南边叉车入口仍被货物占住，会立即结束。入口只是被周围货物围住、暂时没有可出货货组，并不自动判负；仍可能靠后续连接出货打开道路。入库的结束条件保持原样。

普通出库新局和重开会换一个货物序列。中断恢复沿用原局，每日挑战同一天重开也沿用当天序列。

## 退出与存档

回主页或重开要先确认，当前棋盘将结束；取消继续原局，历史成绩和设置保留。后台或意外关闭仍可恢复。无限的“结束并结算”会记本次成绩；普通回主页属于放弃，不能算通关。

已有旧档不会被删除，原先中断的对局仍可继续；这次新增的出库结束条件只适用于新开的对局。旧档和新档成绩按各自规则保留。

## 打开

完整解压试玩包。Windows已安装Node.js时，双击start-preview.cmd；其他系统在解压目录运行node scripts/serve.mjs，然后打开http://127.0.0.1:4173/。预览无需安装项目依赖。仍用原浏览器和相同地址即可读取原存档。

微信开发者工具请导入build/wechat为小游戏，使用自己的AppID。详细验证边界见v070-validation.md。
