# v0.20.0 外观与套装试玩

完整解压后运行 start-preview.cmd，按显示的本地网址进入。相同浏览器与地址保留原记录。道具和47项外观仍可免费领取，已有权益与金币保留。

## 这轮变化
- 外观商店分“套装”和“单件”。十二套系列可查看完整棋盘搭配，拥有三件后可整套应用；单件照常混搭。
- 十三种非初始场景重做净面地砖、材质边框和货口。纹理保持静态，格子边界更清楚。
- 十二种主题叉车统一材质、体块和光照。
- 原木藤箱、霓虹机匣、熔岩石箱、深海珊瑚箱简化小尺寸装饰，让颜色和图标更清晰；其余十款保留清楚的材质。
- 日班仓库、夜班仓库、经典货箱及红、黄、蓝、工程白叉车保持原样。
- 选择“醒目轮廓”恢复经典货箱加清晰描边，不会继续套用上一个冰晶箱体。

玩法、难度、订单、金币、道具效果、音乐及叉车运动时长均未调整。

## 注意
套装预览和美术对照用人工摆放展示五类颜色和特殊状态，不是新增关卡或出库规则；实际出库仍使用原有三类货物。

微信目录可导入开发者工具，需要有权限的开发者自行填写AppID；未在微信真机验证。自动化Canvas/wx宿主不等于真人浏览器或设备测试。
