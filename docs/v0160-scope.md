# v0.16.0 本轮范围

基线v0.15.0（e1c9f70），2026-10-08已确认的同包更新：

- 新加急局按普通分数公式发币，胜利不再额外乘3。订单仍为3–4／3–5／4–5／4–6／5–7，分数仍1倍。以规则21绑定新收益政策；既有钱包和旧19/20局不追回、不重算。相同固定加急得分规则继续共用原最高分分类。
- 待放区每格加急箱显示与棋盘相同的真实剩余数字。初始3，候选等待不减；放上棋盘后按后续有效放置扣数，出货先于报废。拖动、旋转和外观不改变规则。
- 设置按钮组居中，音乐与音效独立。正常5项、有恢复选项时6项，保留等距和触控尺寸。
- 一首本地CC0背景音乐，首次真实触摸后尝试播放、低音量循环。关闭、暂停和后台停止；恢复只延续允许的既有播放。播放失败不影响游戏，不引入运行时联网或新音频依赖。
- 玩具积木／纸艺／太空货运三系列，九件可选外观。主题900、货箱300、叉车600金币；全部原有19项保留，新增后28项。永久拥有、独立装备、自由混搭，保持货类色、特殊标记、数字、前叉和载货位置。每类三页、每页最多4项。

原有玩法说明中的准确用语不改：“加急数字按后续成功放置次数倒数，不是倒计时”。不新增教程、概率或道具机制，不调整五班／无限档位与倍率。一次完成整体验证后交试玩包。

源文档、测试与本地历史持续保存；此前Git远端写入被取消的状态仍暂停，不以本次功能请求替代那次操作的继续授权。真实浏览器／微信设备、音频实际听感和实际循环接缝保留为待验项。
