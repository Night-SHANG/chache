# v1.0.10 暂停布局与全视口遮罩

## 本次范围

- 入库普通、无限、加急，以及出库普通、无限，共用暂停按钮组整体上移200设计像素。
- 按钮首行从 y1090 移到 y890，后续行仍按130像素排列；每个按钮保持588×104，间距26。
- 五按钮组底边为1514，六按钮组底边为1644。原弹窗边界仍为 x173–907、y395–1859。
- 字体、字号、字重、颜色、按钮尺寸、顺序与行间距保持。恢复存档弹窗的继续按钮保持原位置。
- 200像素是根据本游戏说明区和按钮组的实际几何推导的调整量，不是通用平台规范；没有引入新的布局体系。

## 漏亮原因与修复

旧遮罩只绘制逻辑设计区 `(0,0,1080,1920)`。经典场景原有货架会绘制到设计区之外；其他主题沿用v1.0.6确定的有限场景边界。因此宽视口两侧存在已绘制、但未被遮罩覆盖的画面。

平台现在单独提供 `overlayBounds`，将完整实际Canvas按现有缩放、DPR和偏移换算到逻辑坐标，包含安全区边距及上下、左右留边。原 `backgroundBounds`、有限场景边界、背景缩放和输入映射保持不变。

共享遮罩在面板和按钮之前绘制，暂停、恢复、确认、保存阻塞、专供选择、结算、升级等仍使用原0.84不透明度；清扫选择仍使用0.65。只扩大遮罩覆盖区域，不改变这些界面的其他布局。

## 验证

- 新增 `tests/pause-overlay-v110.test.ts`：51项，覆盖13种现行难度/模式组合、5/6按钮几何和输入、四种皮肤、五种视口、DPR1/2/3、四边安全区、存档警告以及十类共享遮罩。
- 联合原布局、场景有限边界、平台缩放、暂停连续性测试，共111项通过。两处原测试使用的暂停继续按钮旧坐标改为读取共享控件几何，保留原断言。
- 未修改的正式浏览器和微信JavaScript产物在原生Canvas宿主中执行，七组场景通过：入库普通/无限、出库普通/无限、加急、安全区高DPR和宽屏。
- 七组未暂停画面与v1.0.9逐像素一致；四组主要暂停画面的22个按钮内部像素，在对应平移后与v1.0.9逐像素一致。
- 验证外侧点击不穿透，继续和重复暂停不改变棋盘。实际Canvas截图单独供用户审阅，不作为项目源文件提交。

上述宿主验证不能替代真实浏览器GUI、微信开发者工具或实体手机验收，也不代表项目全部测试全绿。历史美术母图缺失检查继续保留。
