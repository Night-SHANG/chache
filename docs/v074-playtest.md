# v0.7.4 试玩说明

出库每组动画改为固定1秒：入场、整组装载、载货到对应出口、离场。长路线会加快；连锁仍逐组播放，每组1秒。

装载仍是整组收拢到托盘，车辆沿当前货组清空后的最短安全路线行驶。玩法、计分、旧档和入库演出保持原样。

解压试玩包后，Windows已安装Node.js时双击start-preview.cmd，或运行node scripts/serve.mjs，再打开http://127.0.0.1:4173/。保持原浏览器及同一地址可读取存档。微信开发者工具可导入build/wechat，需自己的AppID；尚未进行真实微信设备验收。

preview目录附实际game.js离屏宿主的原速无声演示，供比较等待时间。真实浏览器、微信设备与真人观感仍需实测。
