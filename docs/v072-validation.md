# v0.7.2 速度与路径验收

2026-10-06。用户实测v0.7.1出库叉车“像窜出去”，本次针对时序与路线修正，不改玩法、计分、入库升级或增加快进操作。

## 根因与修正

此前1.4–3.2秒总预算把每段按权重压缩。4箱北口已有27ms/格、约29ms/90°，80箱最快6.3ms/格，一帧可跨2.63格、转180°。旧测试确认路径合法却没有验证可见速度，不能用通过测试代替玩家感受。

现在每格150ms、每箱140ms、90°转向180ms。直线按整段缓起缓停，不逐空格刹车；转向在格心单独平滑。色口前停180ms，离场240ms，外侧淡出180ms。没有总时长硬压缩，简化动效仍80ms。

保留原入场空路和原树巡回后备。四个有限frontier候选只走原空格或本组已取货格，到未取货格止步、取完再进。按实际移动/转向毫秒选择不劣路线，组内环和安全捷径减少折返。货组事件、cargoPaths与Domain不改；演出中的路线线条同步所选路线，预览仍显示货组连接。

80箱是压力样例；每个箱子都要可见收走时演出会明显更长。本次不掩盖此取舍，也没有把玩家未批准的手动快进或新设置加进去。

完整60fps序列最大约0.167格/帧、12.5°/帧；30fps不超过约0.334格、25°。没有跳过箱子来维持总时间上限。
