# v0.6.0 试玩说明

## 两个主入口

- 入库模式：按订单配货、留叉车通路。7×7。
  - 普通五班：保留原5班、升级与特殊货件。
  - 直接无限：新规则v7，从阶段1起步，每6单提高阶段，到阶段5后持续接单，没有30单通关上限。前30单有原升级机会，之后保留已选升级，不无限叠加。无处落子失败，或暂停后明确“结束并结算”。
  - 本地每日：原客户端北京时间固定种子玩法，非联网赛事。
- 出库模式：同色连出口，叉车能沿空地到货旁。新局9×9，北食品、东化工、西机械出货，南边叉车入场。同色至少4件，30批完成。

## 出库四档

简单纯色80%/双色20%；中等70/30；困难60/40；专业50/50。每档固定逐件概率，不是每十件配额，也不会随形状等级自动切换比例。专业仍是试验基线，没有承诺已平衡。

双色不再只出2×2：方块、横/竖四连、两种L、S、Z和P形共8种形状。每色至少2格、分别四邻接连通；每格独立参与自己的同色组。一次出掉一色，异色留在原位置，继续占位或连接后续货物。T形/十字仍可为纯色；两三格小件保持纯色，以免满地单格残色。

形状先均匀抽取，再抽合法分色，不按棋盘能否摆下救场改抽。共同种子用于以后新局；实际选择与棋盘分化后，不保证每步候选完全相同。

## 退出、重开与恢复

暂停页有继续、重新开始、返回主页与设置。回主页弹出确认：“当前棋盘进度不会保留，已获得的历史成绩和设置不受影响。”点“继续游戏”留在原局；点“结束本局”才弃掉当前棋盘。外点不会确认，弹窗期间不能落子且表现时钟暂停。

重开同样先确认结束当前局。若旧局已经明确结束而新局保存失败，会停在选择页并说明重试，不再声称旧局可继续。

切后台、意外关闭不会主动结束本局，重新打开显示一次恢复提示。暂时读失败可点“重试读取并恢复”；结束记录或存储无法可靠确认时暂停恢复和覆盖，避免用默认记录覆盖历史。

无限模式的“结束并结算”会记录本次得分；普通回主页是放弃当前局，不伪造通关或失败，也不额外计成绩。

## 堵路提醒

预览以本次完整出货连锁之后的棋盘检查，入口被占或空路被切断时显示红色提示和局部标记。若这一步会先出货清路，不误判为堵路。提醒不禁止合法落子，最后放哪里仍由玩家决定。

## 旧档与记录

原入库规则v1–v3不变。旧出库v4/v5仍按7×7和原种子继续，不静默扩为9×9。只有存在旧档时才显示兼容入口；旧档重开进入新9×9难度选择，不再新开旧纯色。新9×9各难度、旧7×7、直接无限和原入库的成绩分开。

## 这次测量说明

100个相同seed×4档，共400局固定机器人策略：简单65胜、中等30胜、困难4胜、专业0胜，0超步数。20,605次有效落子预览/Replay一致，2,648个保存检查点通过。每档10,000件独立生成抽样验证比例与66种图样。

机器人结果只提示空间压力，不等于真人胜率或乐趣。9×9与扩形同时改变，也不能把跨版本胜率当单独扩棋盘的收益。没有据此自动调参；请实际比较四档后再选取。

真实浏览器、Windows实际GUI、微信开发者工具/设备和真人听感/性能仍未完整验收。离屏宿主的实际game.js截图与交互验证不等于这些环境运行通过。
