# v0.15.0 试玩说明

完整解压后，Windows 双击 `start-preview.cmd`。需要已安装 Node.js；启动器会给出本地预览地址。macOS/Linux 可在解压目录运行 `node scripts/serve.mjs`。试玩构建无需安装开发依赖。

## 这次更新

- 加急模式固定为原来的五班订单量：3–4、3–5、4–5、4–6、5–7件。它不受上方困难／专业切换影响，也不再加难度分数倍率。仍可反复开局、带最多两种道具、开局选清扫；通关金币为基础币的3倍。
- 玩法说明中增加独立的“道具说明”。入库说明的“特殊货物”在上，“返回”在下；暂停中查看后可回到当前棋盘。
- 模式卡片的开局按钮统一为“开始”。入库无限显示最多完成订单数，分别保留困难／专业及是否使用道具的纪录。
- 商店增加冷链仓库、铁路货站、快递分拣中心三系列，共九件独立外观。主题900、货箱300、叉车600金币，购买后永久拥有，装备和混搭免费。商品使用分页，翻页只预览。

旧加急存档仍沿原规则，正常结束或重开后体验固定新版。不需要清缓存或删除钱包。确认回主页会结束当前棋盘；后台或意外关闭可恢复尚未结束的局。

本包为本地试玩版。真实浏览器设备差异、Windows图形启动、微信开发者工具与真机、真人手感及平衡仍需实际体验；自动测试与原生Canvas宿主不能代替这些验证。
