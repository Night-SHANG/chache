# 入库直接无限 v7 最小闭环规格

2026-10-06。用户截图明确请求无订单上限、可一直玩；已确认从低阶段逐步成长。新规则v7独立，不能修改原v3五班/每日/加班行为。

- mode=endless、rulesetVersion=7、runConfigId=run.endless_v7。7×7，不含boardSize/difficultyId/colorTier。tutorialStep=3，overtime=false。
- 初始化与普通v3第1班相同的候选、订单和种子算法，身份字段不同。
- 每6单升阶段，阶段最多5；货类/门数/订单量/形状按原阶段增长。达到30单不强制通关，继续第5阶段订单、特殊货件、供货与留路规则追分。
- 升级机会沿用前30单的4/8/12/16/20/24/28阈值；一次有效落子跨多个阈值仍按原一次选择规则，不补一堆升级。30单后停止发新升级，保留已选效果。内容耗尽不生成空选项卡。

- 无合法候选放置时failed/blocked；玩家明确「结束并结算」发finishEndless指令，input阶段可用，进入won/retired作为历史通用结果编码，但UI只显示主动结算，不称通关。finishOvertime/continueOvertime拒绝。
- 升级阶段不能用finishEndless跳过选项；结果后新指令拒绝。暂停/后台/无效落子不消耗规则步数。
- 独立inbound_endless存档键与成绩命名空间。retired不计普通五班胜利/成就；单独显示订单数、得分、峰值占用、升级和结束原因。取消确认不改档，保存失败边界沿用既有保护。
- 主动回主页已确认弃局，只标记当前局结束；该行为不得混为finishEndless，也不得自动记失败或成绩。
