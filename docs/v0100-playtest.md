# v0.10.0 试玩说明

完整解压后，Windows双击start-preview.cmd；继续使用原来的浏览器和 http://127.0.0.1:4173/ 地址即可保留记录。需要已安装Node.js，试玩包无需安装项目依赖。

## 本次变化

- 叉车入口格带通道标识，不能放货。入库四处通道从开局预留，叉车仍按班次开放相应门；出库只预留南侧入口，三个彩色出口仍可放货。
- 出库普通与无限都可在开局前携带最多两种道具。清障用后立即检查出货；旋转保留货件各格颜色，万能箱可选择一种出库颜色。
- 入库加急不再只有单格。整件共用倒数，待放时不减；放入后按后续成功放置次数计时，剩余格到期一起报废。普通与无限每阶段6%，每日12%。首次入库教学仍在第二阶段引入加急。
- 出库得分倍率：简单×1、中等×1.25、困难×1.5、专业×2，普通与无限相同。金币按最后显示的得分换算一次。
- 入库每120分、出库每30分换1金币，不足1金币的部分按单局累计。无限随累计得分增长。每日失败也结算基础金币；首次通关获得三倍基础金币并完成当天挑战，次日重新开放。

商店价格保持旋转80、清障120、万能160。道具确认有效使用才消耗；取消不扣，结束本局退还未使用道具。每日挑战不携带个人道具。

## 继续原记录

无需清缓存。已恢复的旧局保持其原规则；确认结束后再开新局，即可体验本次更新。历史金币、库存和成绩保留。已有旧每日通关记录可能使当天挑战显示已完成，已领取额外奖励不会重复发放。

确认回主页会结束当前棋盘；取消则继续。后台或意外关闭仍可恢复活跃局。首次教学分别记录完成状态，不要求清缓存重置；已经完成的教学不强行重播。

本包含浏览器预览及真实微信小游戏构建目录build/wechat；微信设备验收和正式上传尚未完成。概率与收益为当前试行值，自动测试不能代替真人手感和平衡判断。
