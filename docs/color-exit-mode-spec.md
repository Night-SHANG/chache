# 颜色出口｜独立对比模式规格

2026-10-06。状态：用户已接受逐箱装卸方案A，批准作为独立模式实做后比较。 原订单玩法保留，最终主模式由试玩结果决定。

## 目的与范围

验证固定同色出口是否比动态订单更易理解、更值得重复玩。不是证明哪个玩法已经更好。新增菜单入口与独立局内进度，不替换订单规则v1–v3，不迁移旧档，不用机器人胜率代替真人理解/乐趣。

本阶段沿用7×7、3候选、不可旋转、相同货类4邻接、空格BFS、确定性Replay和原20种Shape目录。只开放食品、机械、化工；不搬入18升级、特殊货件、每日、加班、广告或任何联网功能。

## 固定空间

零基格坐标：南入口(3,6)，北食品出口(3,0)，西机械出口(0,3)，东化工出口(6,3)。每边只有一个单格门，不是整边任意出货。

入口只承担叉车进出，绝不兼作货物出口。货物可摆进入口格，但会堵住唯一叉车入口；预览与状态须明确告警。三个货物出口处的边界格可以放对应货物，以形成与门相连的组。所有门均用图标、文字、颜色区分，不能只靠色觉。

## 出货判定与确定性结算

候选方案的公共部分：
1. 同一货类的上下左右连通组包含对应出口的门边格；斜向不算。
2. 该组数量至少4格。4是本批未平衡P0配置，不是用户已定的最终平衡值。
3. 叉车能从南入口只走空格，到达该组任意邻格；入口占货也算堵路。

一次合法放置后按固定北→东→西顺序检查；本次链完整结算后再判断达到30批，最后允许31/32批。完成一批后清该组，再重新检查尚未完成的出口，可能清路连锁。同一出口本次最多处理一批；结算不生成随机订单，不在动画时再算规则。因为唯一门边格属于一个唯一同色连通组，清走后也不会凭空产生第二个相连组。

数量/颜色出口/BFS全部来自纯规则层；预览与真实命令共用同一选择算法。平局沿用稳定格扫描/邻接顺序。动画只消费事件，不改RNG/score/commands。

## 目标与可调基线

- 累计出货30批完成本局；UI称“批”，不称动态订单。
- 每6批推进一个Shape难度档，最多5档，仅控制原Shape目录的minShift开放；不刷新出口货类或出货量。
- 每格10分；暂不另加路线/升级/连锁倍率，连锁作为记录与反馈展示。
- 三候选全部无合法落点时失败。无自动重抽、免费清盘、继续复活或阈值补偿。
- 无升级、特殊货件。普通Shape权重和拥挤小件倾向复用原配置规则；三货类权重明确版本化，不依赖隐藏救场搜索。
- 数量4、目标30、每档6、分值10、生成权重集中在ruleset4配置，标balanced:false。修改影响序列/得分的参数必须更换规则版本/配置身份，不能使旧Replay换算法。

最低4格只能避免单件/小件贴口即发，不能消除所有贴出口策略。4/5格货件仍可能单次发走。对比须记录“出口邻近放置率、一次货件即出货率、所用出口偏差、入口阻塞、首批时间、失败原因”，保留它是否变成单调贴边游戏的风险，不用未经试玩的惩罚机制掩盖。

## 已定：运输可视语义

用户已明确接受A并要求看实际效果后再调整；B仅保留为此次不采用的比较记录：

A. 逐箱沿连续货线装卸：叉车按南入口空路到组旁，启动装卸；货箱按组内4邻接路径流向对应出口，叉车空载原路退回南入口。动画呈现的是有方向的逐箱装卸通道，不是刚性整组被推出。纯规则可记录各格到出口的确定性货线树，表现按树移动小箱/高亮，不需要3D物理。此方案不额外声称存在叉车携货通往出口的空路。

B. 叉车实际搬到对应出口：必须先定义取货后哪些货格已腾空、载货车可以走哪些格、出货门边格如何腾空、返程是否仍从南门。仅满足上面3条不足以证明载货路径存在。采用此方案须补该可达规则、失败/预览原因与确定性选路，不能拿A的判定配B的动画。

按A实现。不得将其动画改成刚性整组或叉车实际运到彩色出口，除非再确认相应规则变化。

- 新模式成绩独立命名空间，独立统计和结算幂等标记；不计入订单最高分、每日榜、五班成就或百单统计。声音/简化动效/纯外观可共享，但不能让一个模式的成绩解锁或覆盖另一个。

## UI与新手说明

旧模式名“订单”，新模式名“颜色出口·试验”。新模式上方是3个固定出口状态：缺数量/未接对应口/南入口被堵/叉车无空路/此落点预计出货。先解释两件事：货连同色出口、给叉车留空路。有效预览分别显示货线与叉车空路，不以同色线混淆。

首次进入用轻量说明卡明确三条件，并提供固定入口/出口图示；确认开始前不消耗候选或RNG。运行时保留短提示，暂停可重新查看规则，不新增随机教学局来干扰比较。暂停帮助和目标不得沿用“动态订单/旧单/升级/加班”的说明。结果页单列新模式批数/件数/占用/分数，两个玩法不混排。
