原样生产宿主确认外观购买后立即双击同一位置会选择下层商品；没有重复扣款或重复写A/B。根因是InputController既有350毫秒同矩形保护仅识别道具purchase。新增回归先失败，再将识别扩为purchase/purchaseCosmetic/purchaseCosmeticSet；复用时限和区域，未更改布局。覆盖confirm/cancel、单件/固定套装/经典预设及之后正常点击。
