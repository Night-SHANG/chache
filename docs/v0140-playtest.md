# v0.14.0 试玩说明

完整解压后，Windows双击 start-preview.cmd，再打开 http://127.0.0.1:4173/。继续使用原浏览器和同一地址，不用清缓存。

## 本次调整

- 每日挑战改为常驻“加急模式”，可反复游玩，每局重新来货。顶部困难／专业选择同时作用于五班、无限和加急。
- 加急共五班、30单通关，开局先选清扫方式；前四班加急概率6%，末班新货全部加急。现在也可带最多两种工具，每种一件。
- 困难累计得分1.5倍、专业2倍。每120分换1币，加急通关的金币总额为基础币的3倍，失败按基础币结算；使用工具不降低奖励。
- 五班通关后按钮改为“继续无限”。棋盘、累计分数与已用工具接着保留；五班成绩固定，随后完成结算的累计总分计入同档无限成绩。金币只补未领差额。
- 结算按钮间距统一，设置中的声音、简化动效、重置和返回聚拢排列。
- 现有玩法说明已同步为加急模式，用户指定的加急数字句保留。

## 保存与记录

新加急使用规则19，五班／无限仍为18。旧每日局与旧日期账本保留，不会锁住新的加急局，也不会重复领取旧奖励。钱包、库存、外观不清空。

五班之后继续无限，失败或选择“结束并结算”会登记无限成绩。确认返回主页属于放弃当前棋盘，保留已赚金币、退回未用工具，但不登记新增成绩。取消确认则继续原局。后台或意外关闭仍恢复活跃的局。

旧版本已经合并到五班栏的历史加班高分无法可靠拆回30单时的分数，所以保留原值；新结算按以上方式分开。

## 验证边界

本包以本地自动化与未修改的实际 game.js 在原生Canvas/wx模拟宿主中验证。真实浏览器、Windows图形界面、微信设备和真人难度体验仍需对应环境；自动检查不代表难度或金币收益已完成人体验证。
