# v0.23.0 试玩说明

外观直接分套装／场景／货箱／叉车。恢复旧版分页：套装每页4张卡片；单件分类同屏显示旧横幅预览、4个文字选项及上一页／下一页。

普通套装详情返回原页。点击成员可在对应分类浏览，返回套装仍回到原套装及原页；主动切换分类后按普通浏览返回。经典套装保留日班／夜班、经典箱／醒目轮廓、四种叉车，明确装备才应用。

免费试玩可领取道具和外观，不扣金币；领取不会自动装备。正式构建原价格、成就条件和缺失成员八折报价保持。

主页入口默认值和入库／出库等宽菜单保留。玩法、存档格式、图集、音效与背景音乐没有更改。

完整解压后运行 start-preview.cmd，或 node scripts/serve.mjs。微信开发者工具导入 build/wechat。真实浏览器、微信开发者工具／手机体验仍需实际验收。

源码包保留恢复来源和历史缺口说明；不是已找回所有旧版本 Git 历史。
