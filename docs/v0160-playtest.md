# v0.16.0 试玩说明

完整解压后，Windows 双击 `start-preview.cmd`，按提示打开本地地址。需安装 Node.js；macOS/Linux 可运行 `node scripts/serve.mjs`。试玩包无需安装开发依赖。

这次更新：

- 加急模式取消通关3倍金币，新局统一按最终分数÷120取整。固定订单量、得分、清扫和加急出现规则不变；原最高分保留。
- 待放区的加急箱直接显示真实数字3，样式与棋盘一致。待放时不减，放置后才按原规则减少。
- 设置中的按钮组居中，音乐与音效可分别开关。
- 加入一首轻量循环背景音乐。首次点击或触摸后才尝试播放，暂停／后台停止，保留音乐开关选择。
- 商店加入玩具积木、纸艺、太空货运三系列，共九件外观。原有外观全部保留，三类商品各三页；货箱300、叉车600、主题900金币，永久拥有，免费装备和混搭。

旧局仍按它原来绑定的版本结算；重开后进入本次加急规则。不会扣回原有金币或清除钱包、库存、外观。确认返回主页会结束当前棋盘，后台／意外关闭仍可恢复未结束的局。

本地自动验证不代替实际浏览器、微信设备和真人听感；音乐是否在具体设备上连续播放、音量是否合适，仍以实际试玩为准。
