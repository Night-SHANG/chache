# v0.7.2 试玩说明

出库叉车按实际路程行驶，起步、停车和转弯更平缓；每箱收稳后再前进，到色口稍停后离场。环形货组会优先走少绕路的安全路线。

普通几箱的动作现在可以看清，货物越多，演出会更久，不再把整组强行压进几秒。已有“简化动效”仍可使用，没有新增按钮或玩法。

入库演出、两种模式的规则、难度和计分保持原样。旧存档和最高分继续保留。预览文件夹附有原速无声演示，来自本地游戏包的模拟宿主。

完整解压ZIP。Windows已安装Node.js时双击start-preview.cmd；其他系统在目录运行node scripts/serve.mjs，再打开http://127.0.0.1:4173/。继续用原浏览器和相同地址，可读取本地进度。微信开发者工具导入build/wechat为小游戏，填写自己的AppID。

真实浏览器、WindowsGUI和微信设备尚未完整验收，实际手感仍需要试玩；详细验证口径见v072-validation.md。
