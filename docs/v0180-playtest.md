# v0.18.0 试玩说明

本包沿用现有入库、加急和出库玩法，以及免费试玩商店。本轮集中改按钮、文字与货箱外观。

- 领取／购买弹窗右侧确认为黄色，左侧取消为蓝色；选好道具目标后的“确认使用”也是黄色。退出、重开和重置仍优先突出安全选项。
- 报废货物统一称“废弃箱”；特殊货物帮助末尾的重复说明、清障卡的第二行说明已删。万能说明两行保留，效果不变。
- 原木箱和铁角箱升级为“原木藤箱”“铆接钢箱”，已拥有时直接使用新绘制。新增“冰晶货箱”，可在商店→外观→货箱最后一页免费领取，再点击“装备”。保温箱及其他款式仍保留。
- 图标、货类颜色和加急数字仍按当前货物显示；醒目轮廓可以独立叠加。叉车和主题没有变更。

完整逐条对照见[v0.18文案修改](v0180-copy-changes.md)。

完整解压后，Windows已安装Node.js可双击start-preview.cmd；按窗口提示打开本机预览地址。macOS/Linux可在解压目录运行node scripts/serve.mjs。使用相同浏览器与地址保留当前本地记录，不必清缓存。

本包只使用包内音乐与图片资源。图集尚未加载或加载失败时，会用经典货箱保留颜色、图标和数字，游戏仍可操作。试玩领取不会减少金币，领取权益保留。

真实浏览器／微信设备、手感和听感仍需对应环境体验。自动宿主和本机绘制耗时不等于真机验收或真机帧率。
