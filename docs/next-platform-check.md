# 下一步：真实平台验证

v0.8.0 的本地验证结果见 `v080-validation.md`。真实浏览器、Windows GUI 和微信仍须在相应环境单独验收。

## 待验证的浏览器流程

- HTTP预览真实首屏、脚本控制台0错误
- 鼠标拖放；点货件再点棋盘
- Web Locks同源单写入者：第二窗口只读、原窗口关闭后重新进入
- 正常pointer capture结束不会取消点选；8×8新增格、4/5候选与三道具实际触控
- 非法落点/拖出/意外失去捕获/多指中断
- 暂停/升级/结果遮罩不穿透；首次教程、菜单/设置、新局和Profile重置确认/取消
- 标准五班→加班继续/主动退出；本地每日日期口径及跨日恢复
- 声音关闭立即停音、简化动效保留必要反馈且不延长输入阻塞
- 动画中刷新或切后台后只恢复稳定结算结果
- 主档损坏、备份有效；主/备份均损坏；未知未来schema
- 钱包/库存/棋盘共同恢复；后台/刷新/容量耗尽与双副本故障后的实际存储行为
- 出库四档普通/无限、两个独立教程与可选衔接
- 手机长屏/窄屏/DPR与桌面横屏比例

## 微信专属流程

- 正确导入小游戏目录，首次createCanvas上屏
- Android/iOS微信触摸与事件取消
- 屏幕安全区、窗口变化、DPR
- InnerAudioContext声音、后台停止、恢复
- 微信Storage写入失败/超限及持久性
- 弱网/离线不阻挡普通局
- 首屏耗时、包体、内存和长局帧时间

## 目前需要的外部条件

允许本地HTTP访问且可以正常启动安全沙箱浏览器的环境；微信部分还需要官方开发者工具、用户自己的小游戏AppID/权限与扫码手机。不要提供密码、API密钥或上传密钥到聊天。尚未批准上传、审核、发布。
