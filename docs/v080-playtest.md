# v0.8.0 试玩说明

完整解压后，在Windows双击start-preview.cmd。需已安装Node.js；启动器会打开本地预览。macOS/Linux运行node scripts/serve.mjs，再打开http://127.0.0.1:4173/。试玩不需要安装项目依赖。

## 玩法

入库：看订单，凑同图标货组并留空路。普通完成五班；无限持续接单；每日使用当天固定开局。

出库：同色至少4件，上下左右连到同色出口，并让叉车从南入口走到货组旁。简单、中等、困难、专业都可选择普通30批或无限。双色货按各格颜色分别出货，余色留在原格。

首次进入对应模式可跟引导，也可直接开始。暂停页可重开、结束或查看玩法。

## 成长与商店

入库获得7次三选一，可扩仓到8×8、候选增至5件，并取得供货或得分能力。加急货显示3/2/1，之后每次成功放置减1；当步先出货。到期成为废物，依已选的清扫方式处理。

金币可购买旋转、清障、万能直送；新版入库普通或无限开局最多带2件，同类1件。未用的工具结束后退回库存。每日与出库不带个人工具；它们仍可获得金币。价格与收益为试值，无付费购买。

## 记录

同一浏览器、同一地址保留记录，建议仅开一个窗口。确认回主页会结束当前棋盘，保留金币与历史记录；后台中断会恢复。旧局仍按旧规则继续，不追溯兑换金币。

此为本地试玩包。微信构建在build/wechat，导入开发者工具后需由有权限的开发者填AppID；当前未完成真实微信设备验收。
