# v0.7.1 试玩说明

出库叉车现在会逐格收货，载着货从对应颜色的出口离场。

叉车先从南边入口驶到货物旁，叉起相邻箱子再前进；遇到分叉，会沿已经清出的格子折返。大组用托盘上的几只箱子和件数表示，余下的其他颜色仍留在原位。

玩法、四档难度、得分和出货条件保持原样。入库演出也没有改动。大组演出会加速，单组最多约3.2秒；简化动效保留简短反馈。

出库当前得分在对局右上角和结算页，各难度最高分在难度选择页。通关或失败会记录成绩；主动退出或重开属于放弃，不计这局成绩。已有记录和存档继续保留。

完整解压ZIP，Windows已安装Node.js时双击start-preview.cmd；其他系统在目录运行node scripts/serve.mjs，再打开http://127.0.0.1:4173/。仍用原浏览器和同一地址即可读取本地进度。微信开发者工具导入build/wechat为小游戏，填写自己的AppID。

操作、退出与恢复方式沿用v0.7。真实浏览器、WindowsGUI和微信设备尚未完整验收；本地验证详情见v071-validation.md。
