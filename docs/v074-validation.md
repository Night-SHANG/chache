# v0.7.4 固定一秒出库动画验收

用户明确选择每组固定约1秒以减少等待，知晓长路线会加快。此决定取代v0.7.2/0.7.3按格计时，保留v0.7.3整组装载与最短安全离场。

## 时序与边界

每组路线提示0–100ms；入场100–360ms；整组收拢360–500ms；载货路线500–860ms；离场860–960.8ms；在棋盘外淡出至1000ms。采用与入库相同的阶段预算。车辆直线移动按格长、原地转向按弧度×0.22分配各行驶阶段时间，沿现有平滑曲线采样；无单格最低时长或总链条1秒压缩。

只有当前组在500ms变为全部载荷；140ms收拢不按箱数分摊。三出口、旧7×7、新9×9、残色绕行仍走同一最短安全路径。残留异色和未来连锁货不会被提前清空。转弯停留在当前格内，不用帧间直线连线替代拐角；低帧率可能看不到每个中间格，但状态采样仍沿合法分段轨迹。

入库表现、Domain v1–v8、生成概率、规则、计分、存档和声音资产不变。简化动效仍80ms。暂停/后台/确认结束取消表现不会重新触发计分；确认取消保留时钟。连锁各组拥有完整1000ms。
